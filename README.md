# Intro to development
## Description
This is a repository with the intention to help newer developers crack into the field by covering the basics of computing as well as algorithms.

The courese that I'm following are from UW Seattle's Paul Allen program:
- CSE 142: Computer Programming I
- CSE 143: Computer Programming II
- CSE 311: Foundations of Computing I
- CSE 312: Foundations of Computing II
- CSE 331: Software Design and Implementation
- CSE 332: Data Structures and Parallelism
- CSE 421: Introduction to Algorithms
- CSE 521: Design and Analysis of Algorithms I
- CSE 522: Design and Analysis of Algorithms II
- CSE 524: Parallel Algorithms
